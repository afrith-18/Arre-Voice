# Arre-Voice

# 🎙️ Audio Recorder App

A simple **Flutter-based audio recording application** that allows users to record, pause, and save audio files. The app also includes a playback screen to listen to recorded audio.

## 📌 Features
- 🎤 Start and stop audio recording
- ⏸️ Pause and resume recording
- ⏳ Displays recording duration in real-time
- 🔥 Simple UI with intuitive controls
- 📁 Stores recorded audio files locally
- 🎧 Play back the recorded audio
- 🗑️ Delete recorded audio

---

## 🛠️ Technical Specifications

### **🔹 Tech Stack**
- **Flutter** (Framework)
- **Dart** (Programming Language)
- **GetX** (State Management)
- **Flutter Sound** (Audio Handling)
- **Path Provider** (File Management)
- **Permission Handler** (Microphone Permission)

### **🔹 Dependencies Used**
```yaml
dependencies:
  flutter:
    sdk: flutter
  get: ^4.6.5
  flutter_sound: ^9.2.13
  path_provider: ^2.0.11
  permission_handler: ^11.0.0
```

## 🚀 How to Run the App

### **1️⃣ Prerequisites**
Make sure you have the following installed:
- Flutter SDK (Latest Stable Version)
- Dart SDK
- Android Studio or VS Code (Preferred IDEs)
- A physical Android/iOS device or an emulator

### **2️⃣ Clone the Repository**
```sh
git clone https://github.com/your-username/audio-recorder-app.git
cd audio-recorder-app
```

### **3️⃣ Install Dependencies**
```sh
flutter pub get
```

### **4️⃣ Run the App**
```sh
flutter run
```

> **Note:** Make sure your emulator or device has a working microphone.
